# Olist E-Commerce Analysis

Analyzing ~100k orders from Olist, a Brazilian online marketplace, to answer:
**What drives customer satisfaction and repeat purchases, and what should Olist prioritize to improve them?**

🚧 *In progress*

## Data
Download the [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) from Kaggle and place the CSV files in a `data/` folder.

## Tools
SQL (DuckDB) · Python · Power BI
